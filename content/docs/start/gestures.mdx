## In Ink Away

| Gesture | What it does |
| --- | --- |
| Two-finger tap | Undo |
| Two-finger double tap | Redo |
| Two-finger swipe left or right | Turn a notebook's page |
| Long two-finger swipe up | Browse the notebook's folder, or the library from a drawing |
| Long two-finger swipe down | Refresh the screen, clearing ghosting |
| Page turn buttons | Turn a notebook's page, or the book's page in annotation mode |
| Pinch | Zoom |
| Two-finger drag | Move around the page |
| Hold Prev or Next | Jump to the first or last page |

## In KOReader

| Gesture | What it does |
| --- | --- |
| Swipe up the right edge | Open Ink Away, or the book's notes while reading |
| Swipe down the right edge, in a book | Annotate the book |
| Two-finger swipe from the top left to the bottom right, in a book | Copy part of the page |

Ink Away sets these up for you only where they are free, and tells you which you
got. If your reader already uses the right edge, you get two-finger diagonal swipes
instead:

- **Open Ink Away or book notes:** from the bottom right corner toward the top left.
- **Annotate the book:** from the top right corner toward the bottom left.

## Changing them

- **Ink Away's own gestures and pen buttons:** Settings, **Gestures and pen buttons**.
- **The KOReader ones:** KOReader's Settings, **Taps and gestures**, **Gesture manager**. A book has its own gestures, apart from the file browser's, so open a book first to change the book ones. The actions are called **Ink Away: annotate the book**, **Ink Away: book notes**, **Ink Away: copy part of the screen**, and **Open Ink Away** under General.

## A finger while the pen writes

With palm rejection on, **Finger on the page** in the pen settings decides what a
finger does:

- **Navigate:** scroll, turn pages, and hold a picture or shape for its menu.
- **Nothing:** a finger never draws, so a resting hand can't either.
