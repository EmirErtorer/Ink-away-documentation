## Update from the reader

1. Turn on Wi-Fi.
2. Open Ink Away's **Settings**, then **Updates**.
3. You see the latest release and its notes. Tap to install it.
4. Restart KOReader to use the new version.

Ink Away checks the download before installing it.

## The automatic check

Once a day, and only when Wi-Fi is already on, Ink Away looks for a new version by
itself. If there is one, a dot shows on the Settings button. It never turns Wi-Fi
on for this.

## Prereleases

New features go out as prereleases first, for testing on devices I don't have.
**Updates** shows a newer prerelease apart from the latest release, with its notes,
so you choose whether to try it. If you do, reports on how it went are very welcome
on [GitHub](https://github.com/EmirErtorer/ink-away.koplugin/issues).
